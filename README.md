# wayfinder

Δημόσια στοιχεία ελληνικών επιχειρήσεων, δωρεάν.

Το Γ.Ε.ΜΗ. δημοσιεύει τα στοιχεία κάθε ελληνικής επιχείρησης ως ανοιχτά δεδομένα.
Το wayfinder τα δείχνει όπως είναι, με αναφορά στην πηγή και στην ημερομηνία που τα
κατέβασε, και διαβάζει επιπλέον τα βασικά μεγέθη από τους δημοσιευμένους ισολογισμούς.

## Πώς είναι φτιαγμένο

```
site/        Astro, στατικό, σε GitHub Pages. Δεν ξέρει κανένα κλειδί.
worker/      Cloudflare Worker + Durable Object + D1. Το μόνο που μιλάει στο Γ.Ε.ΜΗ.
extractor/   Python. bytes -> dict. Διαβάζει ισολογισμούς, χωρίς δίκτυο.
tools/       Ο runner που τρέχει ο GitHub Actions parser.
data/        Τα μεγέθη που έχουμε ήδη διαβάσει, ως δημοσιευμένο dataset.
```

### Το όριο που καθορίζει τα πάντα

Το Γ.Ε.ΜΗ. επιτρέπει **8 αιτήματα το λεπτό** σε ολόκληρο τον ιστότοπο, με ένα κλειδί.
Ένα token bucket χωρητικότητας 8 **δεν** είναι αυτό το όριο: μπορεί να ξοδέψει 8 αμέσως
και άλλα 7 πριν κλείσει το λεπτό. Γι' αυτό ένα μοναδικό Durable Object βηματίζει κάθε
κλήση τουλάχιστον 10,1 δευτερόλεπτα μετά την προηγούμενη, κρατάει τη θέση πριν στείλει,
και ποτέ δεν μετατρέπει την αδράνεια σε δικαίωμα για ριπή.

Συνέπειες που φαίνονται στον χρήστη:

- Μια εταιρεία που δεν έχει ζητηθεί ποτέ μπορεί να μπει σε ουρά για λίγα δευτερόλεπτα.
- Ό,τι έχει ζητηθεί μία φορά σερβίρεται από το D1 χωρίς να αγγίξει το μητρώο.
- Κάθε απάντηση κουβαλάει `fetched_at`. Ο ιστότοπος δείχνει χρονοσφραγισμένα αντίγραφα.

### Οι αριθμοί των ισολογισμών

Ο extractor διαβάζει **μόνο** PDF με πραγματικό επίπεδο κειμένου. Αντιστοιχίζει κάθε
νούμερο στη στήλη της τρέχουσας χρήσης με βάση τη θέση του κάτω από επικυρωμένη
επικεφαλίδα ετών — όχι με εικασία — και απαιτεί να κλείνει η ταυτότητα του ισολογισμού
πριν δημοσιεύσει οτιδήποτε. Ό,τι δεν διαβάζεται καθαρά επιστρέφεται με λόγο
(`no_text_layer`, `statements_not_attached`, `no_financial_table`) και ο ιστότοπος το λέει.

Λάθος τζίρος είναι χειρότερος από κανέναν τζίρο.

## Ανάπτυξη

```bash
# extractor
cd extractor && python -m venv .venv && .venv/bin/pip install pdfplumber pytest
.venv/bin/python -m pytest -q

# worker
cd worker && npm install --legacy-peer-deps
npx vitest run
npx wrangler dev --ip 0.0.0.0

# site
cd site && npm install
PUBLIC_API_BASE=https://wayfinder.rovas450.workers.dev npm run dev
```
